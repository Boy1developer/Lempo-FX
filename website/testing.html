Testing

CI runs the parity, behavior, and contract checks on every push (.github/workflows/ci.yml).

Naming note: the editor UI is built on Dear PyGui, which wraps Dear ImGui — that is why the UI test files are prefixed test_imgui_.

Running locally

python tools/generate_contracts.py --check   # contract drift gate
python core/test_parity.py                   # Python vs C++
python -m pytest tests/ -q                   # editor + schema suite
node preview/test_ext_trails.mjs             # extension trails headless
python tools/check_perf.py                   # throughput floor

The packaged app has its own smoke path: python editor/studio_imgui.py --smoke 120 boots the UI for 120 frames and reports particle count + FPS.
