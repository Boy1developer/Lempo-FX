Blend Modes

Seven modes, selectable per emitter from the sidebar dropdown — with the same intent everywhere your effect renders.

At object level in GDevelop, BlendingMode: 'JSON' uses each emitter's own mode; any explicit value forces all emitters.

¹ Pixi core has no subtract · ² Pixi core has no lighten · ³ No fixed-function overlay

Fallback policy. Unsupported combinations fall back to Normal with a single console.warn — never per frame, never throwing. Extension versions before 0.1.2 don't know Screen / Lighten / Overlay and render them as Normal.

Blend modes are covered end-to-end by tests: pixel-level GL formulas (tests/test_gl_blend.py), round-trip + sanitize (tests/test_blend_modes.py) and extension mappings with stubbed runtimes (preview/test_blend.mjs). See Testing.
