Lempo Particle FX

Design stunning 2D & 3D particle effects visually in a desktop editor — then play them in GDevelop with the Advanced Particle Emitter extension. The browser preview shares one simulation engine across its renderers; the GDevelop extension keeps a separate runtime.

What's inside?

🖥️

Desktop Editor

Dear PyGui app with live 3D/2D viewport, 12 particle shapes, per-state colors, force fields, deterministic seeds, templates and 100-step undo/redo.

🎬

Trails & Ribbons

Unity-style trail inspector with 79 settings, curve & gradient editors, and 27 ready-made templates across five categories.

👁️

Live Previews

The Dear PyGui viewport uses its drawlist and optional OpenGL raster layer. A separate browser fast preview uses Three.js, PixiJS or Canvas with 500 ms live-sync.

🎮

GDevelop Extension

Advanced Particle Emitter renders your exported JSON in-game — 2D via PixiJS, 3D via Three.js, trails included.

How the pieces fit together

PartWhat it is
Lempo Particle Editor A Dear PyGui desktop app (LempoParticleEditor.exe) for designing effects with a live viewport, then exporting them as JSON.
Advanced Particle Emitter A GDevelop extension (AdvancedParticleEmitter.json) that renders those effects in-game: 2D via PixiJS and 3D via Three.js.

The editor, browser preview and extension share export data contracts. The browser preview's Three.js, PixiJS and Canvas adapters use one TypeScript particle engine; GDevelop still has a separate simulation implementation, so some runtime behavior can differ. See Contracts & Export and the viewport migration notes.

Works in any GDevelop project — design the effect in the editor, play it in-game with the Advanced Particle Emitter extension.
